About

I'm a Senior Cloud Security Engineer with 16+ years building, automating, and securing distributed platforms for regulated enterprises. I work on cloud security posture and policy-as-code — AWS Config, Security Hub, Prowler, Cloud Custodian — with auto-remediation that closes configuration drift instead of filing a ticket about it. I build Zero Trust-aligned platforms: least-privilege IAM and IAM Identity Center, per-pod IRSA on EKS, OIDC short-lived credentials in place of long-lived keys. Security belongs in the pipeline as a first-class gate, not a downstream check. It rests on deep operational roots — re-platforming Hadoop and Spark onto serverless AWS, hardening Kafka and ClickHouse, carrying production incidents at national-telco scale.
